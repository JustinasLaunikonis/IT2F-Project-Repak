Demo 1 Local Call to Word Report
Before starting, make sure the program is installed via the install.bat file
1.	Open the Repak project folder.
2.	Double click run.bat.
3.	Keep the black window open.
4.  A Chrome tab will open automatically
5.	Click List microphones.
6.	Allow microphone access and choose Harm’s microphone.
7.	Tick Also record caller audio from Windows system audio.
8.	Open Call 01 caller.wav in a media player.
9.	Open Call 01 transcript.txt so Harm can read the Technician lines.
10.	Click Start recording.
11.	When Windows asks what to share, choose Entire Screen and tick Share system audio.
12.	Start playing caller.wav.
13.	Harm reads the Technician lines into the microphone. Show that Harm and Caller lines appear in the Call transcript a few seconds after they are spoken.
14.	When finished, click Stop recording.
15.	Wait for Processing to finish. The last few seconds of the call are added to the transcript.
16.	Show the Call transcript and Transcription Model Info.
17.	Fill in any missing details.
18.	Click Generate.
19.	Open the downloaded Word document from Downloads.
20.	Check that the Word document contains the call details and transcript.
21.	Return to the black window and press Control C to stop the application.
