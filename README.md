# IT2F Project Repak

This application listens to a phone call and transcribes what is said. Locally.

## What you need

- A Windows 10 or Windows 11 computer (64-bit)
- An internet connection (only needed while installing)
- Several gigabytes of free disk space
- A microphone

You do **not** need to install anything else first. The installer takes care of Google Chrome, Python, and everything else the application needs.

## Install (only once)

1. **Download the latest prototype.** Go to the [Releases page](https://github.com/JustinasLaunikonis/IT2F-Project-Repak/releases) and find the newest **Prototype** at the top, for example **Prototype 3**.
   Under **Assets**, click **Source code (zip)** to download it.
2. **Unzip it.** Right-click the downloaded ZIP file, choose **Extract All…**, and pick a folder, for example your Desktop.
3. **Run the installer.** Open the unzipped folder and double-click **`install.bat`**.
   - If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway**.
   - If Windows asks *"Do you want to allow this app to make changes?"*, click **Yes**.
4. **Wait.** A black window opens and shows progress. This can take a long time because some downloads are large.
   Keep the window open until it says **installation completed successfully**, then press any key to close it.

> If the installer says you need to **restart your computer**, restart, then double-click `install.bat` again.


## Start the Application

1. Double-click **`run.bat`**.
2. Application opens in Google Chrome by itself.
3. Keep the black window open while you use Repak. To stop the application, close that window.

**Next time, just double-click `run.bat`.** You do not need to install anything again.

## Something went wrong?

- Read the last message in the black window. It usually says what went wrong.
- Check your internet connection, then double-click `install.bat` again. Running it again is safe.
